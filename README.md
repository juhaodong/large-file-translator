## ✨ 主要功能与亮点

### 🚀 一键翻译，无文件大小限制
- **支持超大型 PDF 文件**：不受大小限制，高效处理，节省翻译时间。
- **先进 AI 技术加持**：基于 **GPT-4** 等大模型，翻译精准、流畅，语境自然。

### 🎨 自动识别多种格式
- **内置 OCR 文字识别**：自动提取扫描版 PDF 及图片内文字，轻松翻译不可选文本。
- **兼容复杂排版**：完美支持 **学术论文、技术手册、合同** 等含 **公式、图表** 的文档。

### 🖼️ 保留原版格式
- **精准排版还原**：翻译后文档的 **排版、图片、表格** 与原版保持一致，无需手动调整。
- **多字体适配**：支持 **手写体、特殊字体**，适用于各种翻译需求。

### 🧑‍💻 开箱即用，无需复杂操作
- **三步完成翻译**：上传 **→** 自动处理 **→** 下载，操作简单高效。
- **无需注册或登录**：即开即用，界面友好，适合所有用户。
